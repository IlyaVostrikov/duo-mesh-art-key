# T02 — Stored XSS на маркетинговом сайте (unescaped innerHTML)

- **Приоритет:** 10/10
- **Стадия:** Stage 1
- **Область:** website
- **Статус:** backlog

## Что не так

Пять astro-страниц строят карточки/детальные страницы, инжектируя строки из API (имя художника, title/description арт-объекта) в `innerHTML`-шаблоны **без экранирования**:

- `website/src/pages/artworks.astro` (L70-77)
- `website/src/pages/artworks/[id].astro` (L44-72)
- `website/src/pages/artists.astro` (L43-51)
- `website/src/pages/artists/[id].astro` (L38-64)
- `website/src/pages/halls/[slug].astro` (L35-53)

Только `verify.astro` имеет локальный `escapeHtml()` (L173-175), остальные — нет.

## Почему это важно

API возвращает **авторский** контент. Злонамеренный художник может внести `<img onerror=…>` / `<script>` в title/description, и он выполнится в браузере каждого посетителя публичного сайта — классический stored XSS на «парадном входе» компании. Компрометация любого посетителя (кража cookie, редиректы, подмена контента).

## Локализация

- `website/src/pages/verify.astro:173-175` — существующий локальный `escapeHtml()` (донор).
- 5 страниц выше — все интерполяции.

## Минимальная правка

1. Вынести `escapeHtml()` в `website/src/lib/escape-html.ts` (общий модуль).
2. Импортировать и обернуть **каждую** интерполяцию в `innerHTML`-шаблонах на всех пяти страницах.

## Подводные камни

- **Не только title/description.** В `artworks/[id].astro` в `innerHTML` попадают также `year`, `medium`, `editionTotal`, `styleTags`, `dimensions`, `keyCode`, `ownerKey` — обернуть **все** поля, а не три «очевидных».
- **Экранировать перед вставкой в HTML-контекст** (не в текст атрибута). Для атрибутов (`title="…"`, `alt="…"`) нужна экранировка кавычек, а не только `<>`.
- **Не дублировать `escapeHtml` по страницам** — один модуль, иначе снова разъедется.
- Не переписывать страницы на React-islands в этой задаче — только минимальное экранирование (island-переписывание — отдельная работа, см. T13).

## Приёмочные критерии

1. Художник с именем `<img src=x onerror=alert(1)>` в БД → на публичной странице показывается текст, скрипт не выполняется.
2. `git grep -n "innerHTML" website/src/pages` — каждая найденная интерполяция обёрнута в `escapeHtml`.
3. `bun run --cwd website build` проходит.
4. Поле с двойной кавычкой корректно отображается в атрибутах (не ломает разметку).

## Валидация

```bash
bun run --cwd website build
# ручная проверка в браузере на проде/preview: страница художника с инжектированным именем
```
