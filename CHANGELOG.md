# Changelog

## 0.1.0 (2026-08-02)

Security remediation — 27 fixes from full code audit.

### P0 — Critical (10)

- **P0-01:** ArtKey genesis wrapped in `$transaction` with TOCTOU re-check
- **P0-02:** Artwork visibility bypass fixed — viewerUserId/viewerRole propagated, ownership checks enforced
- **P0-03:** Artwork mutation authorization — `verifyOwnership()` added to services, routes deduplicated
- **P0-04:** ADMIN→ARTIST role downgrade on onboarding fixed — guard added
- **P0-05:** ZIP bomb protection — metadata pre-validation before `unzipSync`
- **P0-06:** `verifyTimestampToken` now throws (was always returning `{valid: true}`)
- **P0-07:** Self-assignable roles stripped from registration — role hardcoded to `GUEST`
- **P0-08:** Error response format standardized — all 11 routes use `errorResponse()`
- **P0-09:** Seed endpoint hardened — SHA-256+timingSafeEqual, header-only token, rate limiter
- **P0-10:** Key rotation order fixed — create new key before deactivating old ones

### P1 — Important (14)

- **P1-01:** Hall create/update authorization added
- **P1-02:** Platform key recoverable after cold start via DB sync
- **P1-03:** `ProvenanceTransferService.createTransfer` made atomic with `$transaction`
- **P1-04:** `ArtistService.update()` authorization added
- **P1-05:** Certificate PDF fetch timeout added
- **P1-06:** Hardcoded featured mappings replaced with DB-driven data
- **P1-07:** Sale service pagination added
- **P1-08:** Keystore concurrency race fixed — write lock serialization
- **P1-09:** Transfer error handler `as 200` type assertion removed
- **P1-10:** Inquiry authorization on non-public artworks fixed
- **P1-11:** Hall view count error isolation — no longer brings down whole request
- **P1-12:** SHA-256 KDF replaced with PBKDF2 (600K iterations) + random salt
- **P1-13:** `extractGenTime` no longer silently returns `new Date()` on error
- **P1-14:** Email enumeration via timing side-channel fixed

### P2 — Polish (3)

- **P2-01:** Incorrect private key size comment fixed
- **P2-02:** Keystore file race on concurrent writes (fixed with P1-08)
- **P2-03:** Typo `provenanceTranferSvc` → `provenanceTransferSvc` fixed

### Deploy notes

- **Before deploy:** run `bun run scripts/migrate-kdf.ts --dry-run` then without flag (P1-12)
- Keystore now requires `<storePath>.salt` file (generated by migration script)
- PBKDF2 with 600K iterations replaces SHA-256 for key derivation
