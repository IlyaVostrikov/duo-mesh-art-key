# ArtKey — Provenance Landing (Handoff)

Кинематографичный scroll-storytelling лендинг для **ArtKey** — криптографической
provenance-системы для искусства. Музейный минимализм, тёплый монохром,
typography-first, анимация на canvas + scroll.

## Что это за файлы
Это **дизайн-референс, собранный на чистом HTML/CSS/JS** — рабочий прототип,
показывающий внешний вид и поведение. Это не обязательно прод-код: если вы
переносите лендинг в Next.js / React / другой стек, воспроизведите этот дизайн
средствами вашего окружения. Если отдельного окружения нет — файлы можно
деплоить как есть (статика, без сборки).

## Как запустить локально
Нужен любой статический сервер (из-за того, что подключаются внешние .js/.css
и canvas — `file://` может блокировать часть запросов шрифтов):

```bash
cd artkey_handoff
python3 -m http.server 8000
# открыть http://localhost:8000/ArtKey.html
```

Или с Node:
```bash
npx serve .
```

## Структура
| Файл | Назначение |
|------|-----------|
| `ArtKey.html` | Разметка всех сцен лендинга. Точка входа. |
| `artkey.css`  | Все стили + дизайн-токены (CSS-переменные в `:root`). |
| `artkey.js`   | Движок анимаций: ambient-частицы, reveal, scroll-сцены, canvas. |
| `image-slot.js` | Веб-компонент drag-and-drop плейсхолдера (в этой версии hero рисуется на canvas, slot оставлен для сцены верификации при желании). |

> В `ArtKey.html` подключения CSS/JS идут с query-параметром версии
> (`artkey.css?v=9`, `artkey.js?v=12`) — это просто cache-busting. При переносе
> можно убрать `?v=...`.

## Архитектура анимации (важно)
Весь «движ» управляется **одним rAF-циклом** в `artkey.js` (функция `pass()` →
`runScenes()`), а состояние большинства элементов — **чистая функция позиции
скролла** (не таймеров). Это сделано намеренно: анимации плавные,
детерминированные и не «уезжают» при перемотке. Сцены регистрируются через
`register(el, render, scrub)`:
- `scrub:true` — `render(p)` получает прогресс `p` 0→1 по мере прохождения секции
  (секции высокие, с `position:sticky` внутри).
- `scrub:false` — непрерывная анимация по времени (hero, финальное созвездие).

`prefers-reduced-motion` поддержан — анимации сводятся к статичным конечным
состояниям.

## Дизайн-токены (`:root` в artkey.css)
```
--paper      #f4f3f1   фон (музейный тёплый свет)
--paper-2    #ece9e4
--paper-3    #e0ddd6
--ink        #16140f   основной текст (тёплый near-black)
--ink-2      rgba(22,20,15,.62)
--ink-3      rgba(22,20,15,.40)
--hair       rgba(22,20,15,.14)   тонкие линии
--noir       #0c0b0a   тёмные сцены (рождение подписи, финал)
--on-noir    #efece6   текст на тёмном
--hair-noir  rgba(239,236,230,.16)
Шрифты:  --font-display 'Space Grotesk' (заголовки/текст)
         --font-mono    'Space Mono'    (хеши, технические подписи)
--ease   cubic-bezier(.22,.61,.16,1)
--maxw    1320px
```
Палитра — строгий монохром (без цветовых акцентов).

## Сцены (порядок по скроллу)
1. **Hero** — «живое» полотно на canvas (`#hero-canvas`): по работе идёт волна
   реконструкции, пиксели поднимаются в координатные точки и оседают обратно;
   снизу табличка подлинности с пульсом и бегущим отпечатком. Манифест-заголовок.
2. **Манифест / What is ArtKey** — определения: Отпечаток / Цепочка / Контроль.
3. **Рождение SHA-256** (тёмная) — `#sha-canvas`: картина → координатная сетка →
   рассыпается в точки → сходится в светящуюся подпись; хеш «рождается» посимвольно
   над заголовком «Один отпечаток. Невозможно подделать.»
4. **Цепочка владения** — `#chain`: линия времени с медальонами-иконками ролей
   (Художник → Коллекционер → Галерея → Аукцион → Коллекционер); светящийся пульс
   едет по линии, узлы «защёлкиваются» (иконка прорисовывается штрихом, кольцо-пульс,
   хеш-чип).
5. **QR-верификация** — split: слева образец работы со сканлайном и QR, справа
   три пункта provenance (Оригинал / Художник / История) с анимированными галочками.
6. **Финал** (тёмная) — созвездие работ, связанных provenance-линиями, statement
   «Искусство должно иметь память», 3 CTA: Explore Gallery / Verify Artwork / Issue ArtKey.

## Зависимости
Только Google Fonts (Space Grotesk + Space Mono) — подгружаются через `@import`
в `artkey.css`. Внешних библиотек нет, сборка не требуется.
